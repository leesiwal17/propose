💍 게임 방법 (병맛 에디션)

1. 역할 분담: 매 라운드 한 명이 '고백받는 주인공'이 되고, 나머지 플레이어들은 모두 '구혼자'가 됩니다.

2. 비밀리에 문장 조립: 구혼자들은 기기를 한 명씩 넘겨받으며, 무작위로 지급된 7장의 병맛 단어 카드와 기본 조사/어미 카드를 조합해 세상에 둘도 없는 프로포즈 문장을 만듭니다.

3. 패 교체 찬스: 단어가 너무 노답이라면 턴당 1번, 최대 3장까지 버리고 새 카드를 뽑을 수 있습니다!

4. 절절한 고백 타임: 모든 구혼자의 문장이 완성되면, 한 명씩 화면을 보며 최대한 느끼하고 진지한 목소리로 프로포즈를 낭독합니다.

5. 반지 수여: 고백받는 주인공이 가장 마음에 들거나 웃긴 고백을 선택해 반지(💍)를 줍니다. 목표 반지 개수를 먼저 모으는 사람이 최종 승리!
